# BeeHome Planner Backend (MVP)

TypeScript + Express + Prisma backend for BeeHome Planner.

## Quickstart

- Install: `npm install`
- Dev: `npm run dev`
- Typecheck: `npm run typecheck`
- Tests: `npm run test`
- Generate OpenAPI: `npm run openapi:generate`

## Environment

Copy `.env.example` to `.env` and fill in values.
